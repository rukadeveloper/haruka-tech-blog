<p><strong>Nest.js 소개</strong></p><ul><li><p>효율적이고, 스케일링이 쉬운 NodeJS 서버를 만드는데 사용하는 프레임워크</p></li><li><p>차세대 Javascript를 사용하며, Typescript로 만들어졌으며, Typescript를 완전 지원한다</p></li><li><p>Express 같은 견고한 HTTP 서버 프레임워크를 사용한다.</p></li><li><p>상당히 많은 NodeJS 라이브러리, 헬퍼, 툴 등이 있음에도 아키텍처 설계에 대한 해결책은 존재하지 않았다.</p></li><li><p>자체적으로 서버 아키텍처를 제공하며, 테스트하기 쉽고 유지보수가 편한 서버를 제작해준다.</p></li></ul><p><strong>Windows에서의 환경설정</strong></p><p>먼저, NodeJS 공식 사이트를 통해 LTS 버젼을 다운받습니다.</p><p><a target="_blank" rel="noopener noreferrer nofollow" href="https://nodejs.org/ko/download">https://nodejs.org/ko/download</a></p><p>Node.js — Node.js® 다운로드Node.js® is a free, open-source, cross-platform JavaScript runtime environment that lets developers create servers, web apps, command line tools and scripts.nodejs.org</p><p>이후, Windows Powershell에 관리자 권한으로 접속해 다음과 같은 명령어를 입력합니다.</p><p></p><img src="/images/posts/73/1.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>다음으로, npm과 yarn 버젼도 확인합니다.</p><p></p><img src="/images/posts/73/2.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>npm이 정상적으로 설치되었으므로, <strong>npm install -g @nestjs/cli</strong> 명령어를 칩니다.</p><p>이렇게 되면, Nest.js 코드를 터미널에서 실행할 수 있는 CLI 툴이 설치됩니다.</p><p><strong>http를 이용해 기본 서버 만들기</strong></p><p>Nest.js의 아키텍처를 더 쉽게 이해하기 위해 먼저 기본 NodeJS의 라이브러리를 사용하여 서버 구축을 해봅니다.</p><p>NodeJS에서 기본으로 제공해주는 http 패키지를 사용해서 간단한 서버 구축을 해보겠습니다.</p><p>루트 폴더에 <strong>server.js</strong> 라는 파일을 생성합니다.</p><p>먼저, require라는 CommonJS 문법을 사용하여 http 패키지를 가져옵니다.</p><pre><code class="language-javascript">const http = require('http')
</code></pre><p>그리고, 호스트와 포트 번호를 저장합니다.</p><pre><code class="language-javascript">const host = 'localhost'
const port = 3000
</code></pre><p>여기서 localhost는 127.0.0.1 이라는 IP를 의미하고, 이것은 Loop Back이라고도 하며, 서버를 실행한 컴퓨터입니다.</p><p>이제 http를 통해 서버를 만듭니다.</p><p>createServer 함수를 이용해, 서버를 만들고, 어떤 요청과 응답을 어떻게 처리할지 설정합니다.</p><pre><code class="language-javascript">http.createServer((req, res) =&gt; {
  res.writeHead(200, { 'Content-Type': 'text/html' })
  res.end('&lt;h1&gt;Hello World&lt;/h1&gt;')
})
</code></pre><p>응답으로 Status Code를 넣기 위해 writeHead 함수를 사용하며, header 객체를 추가합니다.</p><p>마지막으로, end 함수를 통해 실제 어떤 데이터를 보내줄지 명시합니다.</p><p>이제 서버를 생성을 했으니 서버를 실행을 해야합니다. 앞서 createServer에서 반환값을 받습니다.</p><pre><code class="language-javascript">const server = http.createServer((req, res) =&gt; {
  res.writeHead(200, { 'Content-Type': 'text/html' })
  res.end('&lt;h1&gt;Hello World&lt;/h1&gt;')
})
</code></pre><p>이제 서버 객체에서 listen 함수를 통해 host와 port에서 서버를 듣도록 만듭니다.</p><pre><code class="language-javascript">server.listen(port, host, () =&gt; { console.log('server running on http://localhost:3000') })
</code></pre><p>이제 터미널에서 <strong>node server.js</strong> 실행문을 통해 서버를 실행시킵니다.</p><p></p><img src="/images/posts/73/3.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>이제 <a target="_blank" rel="noopener noreferrer nofollow" href="http://localhost:3000/">http://localhost:3000/</a> 에 접속해 서버에 요청을 넣습니다.</p><p></p><img src="/images/posts/73/4.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>응답으로 이렇게 h1 태그가 나오면 성공입니다.</p><p><strong>Express.js로 RESTful API 구현하기</strong></p><p>먼저 Express.js의 설치하기 위해 npm 초기화를 해줍니다.</p><p></p><img src="/images/posts/73/5.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>그러면 <strong>package.json</strong> 파일에 여러가지 정보가 담깁니다.&nbsp;</p><p>이제 <strong>npm install express</strong>를 통해 설치합니다.</p><p></p><img src="/images/posts/73/6.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>이제 본격적으로 코드를 작성해보겠습니다. 먼저, express 패키지를 불러옵니다.</p><pre><code class="language-javascript">const express = require('express')
</code></pre><p>그리고 express를 실행합니다.</p><pre><code class="language-javascript">const app = express()
</code></pre><p>이제 이 app 변수에 원하는 엔드포인트들을 붙일 수 있습니다. http method들을 함수로 사용합니다.</p><p>예를 들어, get 요청을 보내는 함수를 작성할 것인데, 첫번째 파라미터에는 라우팅될 path를 넣습니다.</p><p>두번째 파라미터에는 req, res를 파라미터로 받는 콜백 함수를 넣어줍니다.</p><p>이제 응답값으로 어떤 객체나 값을 반환하려면, res.send 함수를 사용하면 됩니다.</p><p>이러면, 첫번째 파라미터의 엔드포인트로 요청이 들어오면, 두번째 파라미터의 콜백 함수로 라우팅 됩니다.</p><pre><code class="language-javascript">app.get('/', (req, res) =&gt; {
    res.send('&lt;h1&gt;Home Page&lt;/h1&gt;')
})

app.get('/post', (req, res) =&gt; {
    res.send('&lt;h1&gt;Post Page&lt;/h1&gt;')
})
</code></pre><p>반대로, 404 에러 처리를 위해서는 app.use 함수를 사용합니다.</p><p>위에서 라우팅 처리된 엔드포인트 이외에 경우에 use 함수로 트리거된다고 생각하면 됩니다.</p><pre><code class="language-javascript">app.use((req, res) =&gt; {
  res.status(404).send('&lt;h1&gt;Error Page&lt;/h1&gt;')
})
</code></pre><p>이제 express도 서버를 listen 시킵니다.</p><pre><code class="language-javascript">app.listen(3000, () =&gt; {
  console.log('server running on http://localhost:3000')
})
</code></pre><p>이후에 <strong>node server.js</strong>를 통해 서버를 실행하고 확인합니다.</p><p>이를 통해 확인할 점은 현재 엔드포인트는 2~3개밖에 되지 않아 한 파일에서 처리했지만,</p><p>엔드포인트가 기하급수적으로 많아지고 비즈니스 로직이 복잡해지면 파일 및 아키텍처 관리가 필요해집니다.</p><p>이를 위해 Nest.js 프레임워크가 등장했습니다.</p><p><strong>Nest.js 통한 hello-world</strong></p><p>먼저 Nest.js 초기 셋팅을 위해 Nest CLI를 사용합니다. <strong>[nest new [project_name]]</strong> 명령어를 입력해주세요.</p><p></p><img src="/images/posts/73/7.png" alt="" data-align="center" style="display: block; height: auto; max-width: 100%; margin: 0px auto;"><p>여러 체크 옵션에 대해서는 자유롭게 체크하시고 설치합니다.</p><p>일단 Nest.js가 어떤 아키텍처로 구성되어 있는지 알아봅시다.</p><p><strong>1. main.ts -&gt; Nest.js 프로젝트를 시작하는 파일</strong></p><p><strong>2. app.service.ts -&gt; 비즈니스 로직 / 기능 구현에 사용되는 파일</strong></p><p><strong>3. app.module.ts -&gt; Controller와 Service를 포함하는 Provider 관리 (의존성 관리)</strong></p><p><strong>4. app.controller.ts -&gt; HTTP 메소드를 통해 요청에 대한 응답을 처리하는 구간</strong></p><p><strong>5. app.controller.spec.ts -&gt; app.controller.ts에 있는 코드에 대한 테스트</strong></p><p>예시로 app.controller.ts 코드를 다음과 같이 수정해서 엔드포인트를 여러 개 만들어봅시다.</p><pre><code class="language-javascript">import { Controller, Get } from '@nestjs/common';
import { AppService } from './app.service.js';

@Controller()
export class AppController {
  constructor(private readonly appService: AppService) { }

  @Get()
  getHome() {
    return 'Home Page'
  }

  @Get('post')
  getPost() {
    return 'Post Page'
  }

  @Get('user')
  getUser() {
    return 'User Page'
  }
}
</code></pre><p>이를 통해 Express.js를 제대로 구조화된 아키텍처가 Nest.js 임을 이해할 수 있었습니다.</p>
