**기본 데이터 타입**

첫번째는 숫자(정수, 실수) 데이터입니다. 숫자 데이터에는 int(정수), float(실수) 타입이 있습니다.

두번째는 문자열(str) 데이터입니다. 아래는 Python에서 문자열을 만드는 방법입니다.

```python
print("Python") # 'Python'
print('Python') # 'Python'
print("""Python""") # 'Python'
print('''Python''') # 'Python'
```

문자열에서 ""와 ''를 모두 제공하는 이유는 문자열 데이터 중 '가 포함되는 문장의 경우 ''로 처리할 수 없기 때문입니다.

또한 여러줄의 문장에서 줄바꿈하여 처리할 때, ""나 ''는 제공하지 않기 때문에 """나 '''를 제공합니다.

문자열은 특이하게 + 연산 혹은 공백으로 인접한 문자열끼리는 자동으로 연결해줍니다.

```python
print("Hello" + "World") # HelloWorld
print("Hello" "World") # HelloWorld
```

문자열은 또 \* 연산을 통해 반복 연산을 제공합니다.

```python
print("Hello" * 3) # HelloHelloHello
```

또 문자열의 크기를 반환하는 함수를 제공합니다. 다만 공백도 문자에 포함됩니다.

```python
print(len("Hello World")) # 11
```

세번째는, bool 타입입니다. bool 타입은 True(참) 혹은 False(거짓) 값만 갖는 논리 타입입니다.

Python에서는 기본적으로 비교 연산자(<,<=,>,>=,==,!=)를 제공하는데 이것의 결과값이 bool 타입입니다.

```python
print(20 > 10) # True
print(20 < 10) # False
print(20 >= 20) # True
print(20 < 20) # False
print(20 <= 20) # True
print(20 == 20) # True
print(20 != 20) # False
```

  
네번째는, None 타입입니다. None 타입은 아무런 값도 없는 특별한 데이터 타입입니다.

**변수(Variables)**

변수는 데이터를 담아두는 공간입니다. 이름을 정해서 담아두며, 이것을 변수 이름(variable name)이라고 합니다.

변수의 데이터는 언제든지 변할 수 있으며, 대입 연산자를 사용하여 **\[변수명 = 값\]** 으로 사용합니다. 

변수를 제거하기 위해서는 del 키워드를 통해 사용합니다.

```python
name = "John"
del name
```

Python에서는 여러 변수를 한 줄에 선언하는 문법도 제공합니다. 아래와 같이 사용합니다.

```python
a, b, c = 10, 20, 30
```

이것을 이용해 변수의 값을 교환할 때, temp 변수를 사용하지 않고, 한번에 교체합니다.

```python
a = 33
b = 11
print(a, b) # 33, 11

a, b = b, a
print(a, b) # 11, 33
```

변수를 저장하기 위해서는 변수명을 지어준다고 했는데 이를 위해서 식별자 명명 규칙을 이해해야 합니다.

-   **알파벳, 숫자, \_ 등은 사용할 수 있습니다.**
-   **숫자로는 시작할 수 없습니다.**
-   **변수명에 띄어쓰기는 불가합니다.**
-   **특수문자는 사용 불가합니다.**
-   **Python의 예약어는 사용 불가합니다.**

**print() 함수**

print()는 Python에서 가장 기본적인 출력 함수입니다. print() 함수는 출력한 뒤에 자동으로 줄바꿈이 적용됩니다.

```python
print(10, 20, 30) # 10 20 30
print('hello') # hello
print(3.14) # 3.14
```

print() 함수는 사용할 수 있는 옵션이 있는데 그 중 하나가 end parameter입니다.

이는 출력이 끝난 뒤 마지막에 출력하는 문자열이며, 디폴트 값은 줄바꿈을 수행하는 문자인 \\n 입니다.

예를 들어, end parameter에 -- 문자열을 셋팅하면 다음과 같이 출력됩니다.

```python
print(10, 20, 30, end='--') # 10 20 30--
```

print() 함수는 또 사용할 수 있는 옵션인 sep parameter가 있습니다.

이는 출력할 값들 간의 구분 문자열을 의미합니다. 디폴트 값은 빈 문자열인 " "입니다.

예를 들어, sep parameter에 -- 문자열을 셋팅하면 다음과 같이 출력됩니다.

```python
print(10, 20, 30, sep='--') # 10--20--30
```

**문자열 포맷팅**

서식화된 문자열로써, 크게 3가지 방식으로 나뉩니다.

**1\. % 연산자를 사용하는 방법**

서식 지정자(format specifier)를 포함한 문자열과 그것에 대응하는 데이터를 연결하여 문자열을 완성합니다.

```python
fmt = "내 이름은 %s, 나이는 %d살 "
print(fmt % ("홍길동", 20)) # 내 이름은 홍길동, 나이는 20살
```

서식 지정자에는 %d(10진수 정수), %f(실수), %s(문자열), %%(문자 자체) 등이 있습니다.

**2\. format() 함수 사용**

문자열에 데이터로 대응할 부분을 {}로 처리하고, format 함수의 파라미터로 그 데이터를 대응시킵니다.

```python
fmt = "My name is {}, I'm {} years old"
fmt.format("박수진", 10) # My name is 박수진, I'm 10 years old
```

또는 {} 안에 변수명을 넣어서 parameter에 변수명을 넣습니다.

```python
"My name is {name}, I'm {age} years old".format(name="박수진", age=10)
```

**3\. f-string 사용**

format()의 발전된 형태로 f'' 형태로 작성하며, {} 안에는 변수 이름 혹은 문자열을 맵핑시킵니다.

```python
lang = 'Python'
author = 'Guido van Rossum'

print(f'Language: {lang}, Author: {author}')
```

**이스케이프 문자**

문자열 내에서 특수한 문자를 출력할 때 사용합니다.

-   \\n : 줄바꿈
-   \\t : 탭
-   \\\\ : 역 슬래시
-   \\' : 홀 따옴표
-   \\": 쌍 따옴표

혹은 파일 경로, URL 주소들은 이스케이프 문자가 아니라 r'' 형태로 작성할 수 있습니다.
