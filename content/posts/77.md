**판다스(pandas)**

판다스는 행(row), 열(column) 형태의 정형화된 2차원 데이터를 다루며, 엑셀의 Sheets, RDB의 Table이 그 예시입니다.

대표적인 판다스에서 제공하는 객체는 데이터프레임(DataFrame)과 시리즈(Series)가 있습니다.

먼저 판다스를 임포트합니다.

```python
import pandas as pd
```

**시리즈(Series)**

넘파이의 ndarray 기반으로 인덱싱 기능이 추가된 1차원 배열을 나타냅니다. Index 과 Value의 형태입니다.

인덱스(Index)를 지정하지 않을 시 기본적으로 ndarray와 같이 zero-based Index가 생성되며,

지정하면 명시적으로 지정된 Index를 사용합니다.

본격적으로, 판다스의 시리즈를 생성해보겠습니다.

```python
s1 = pd.Series([10, 20, 30])
s1
```

![](/images/posts/77/2.png)

각 시리즈에서의 속성을 알아보겠습니다.

첫번째, 시리즈에서의 값입니다.

```python
s1.values # array([10, 20, 30])
```

두번째, 시리즈에서의 인덱스입니다. 기본적으로 zero-based Index입니다.

```python
s1.index # RangeIndex(start=0, stop=3, step=1)
```

세번째, 시리즈에서의 데이터 타입입니다.

```python
s1.dtype # dtype('int64')
```

그래서 인덱스 속성을 통해 인덱싱 연산이 가능합니다.

```python
s1[0] # np.int64(10)
```

이번엔 data와 index를 명시하여 시리즈(Series)를 생성하는 방법을 알아보겠습니다.

```python
s2 = pd.Series(data=[1, 2, 3], index=[100, 200, 300])
s2
```

![](/images/posts/77/3.png)

그리고, index는 굳이 정수일 필요는 없습니다.

```python
s3 = pd.Series(data=[1, 2, 3], index=['john', 'mark', 'charlie'])
s3
```

![](/images/posts/77/4.png)

하지만 이럴 때 인덱싱은 인덱스 명칭을 제대로 부여해야 합니다.

```python
s3['john'] # np.int64(1)
```

그리고, 인덱싱은 중복을 허용합니다.

```python
s4 = pd.Series(data=[1, 2, 3], index=['john','john','charlie'])
s4
```

![](/images/posts/77/5.png)

이 때 중복된 인덱스인 john을 인덱싱하면 결과가 Series가 나옵니다. 차원 감소가 없습니다.

```python
s4['john']
```

![](/images/posts/77/6.png)

그리고, dict를 통해서도 Series 생성이 가능합니다.

dict의 key가 index로, value가 value로 맵핑됩니다.

```python
sdata = {'김철수': 35000, '이상현': 67000, '최종수': 12000, '박진관': 4000}
s5 = pd.Series(sdata)
s5
```

![](/images/posts/77/7.png)

Series의 인덱싱에 대해 자세히 알아보겠습니다. 아래와 같은 시리즈가 있다고 가정합시다.

```python
s6 = pd.Series(data=np.arange(5), index=np.arange(100, 105), dtype=np.int16)
s6
```

![](/images/posts/77/8.png)

이를 통해 이 Series의 Index 객체를 확인해보면 100, 101, 102, 103, 104일 것입니다.

```python
s6.index # Index([100, 101, 102, 103, 104], dtype='int64')
```

Index 객체에 values 속성으로 들어가면 ndarray 객체가 나옵니다.

```python
s6.index.values # array([100, 101, 102, 103, 104])
```

인덱싱 값을 통해 인덱싱 처리하면 0차원 스칼라 값이 나옵니다.

```python
s6[102] # np.int16(2)
```

리스트를 씌워 인덱싱 처리하면 1차원 배열 즉 Series가 나옵니다.

```python
s6[[102]] # Series
```

![](/images/posts/77/9.png)

value를 변경하고 싶다면 인덱싱 후 수정하면 됩니다.

```python
s6[104] = 70
s6
```

![](/images/posts/77/10.png)

기존에 없던 인덱스에 값을 대입하면 새로 생깁니다. (이것은 넘파이와 다른 점이며, Python의 dict와 유사합니다)

```python
s6[105] = 90
s6
```

![](/images/posts/77/11.png)

Series의 연산에 대해 알아보겠습니다. Series의 연산은 index 기준으로 연산합니다.

아래와 같이 서로 인덱스가 다른 Series의 예시를 살펴봅시다.

```python
s1 = pd.Series(data=[1, 2, 3, 4], index=['a', 'b', 'c', 'd'])
s2 = pd.Series(data=[6, 3, 2, 1], index=['d', 'c', 'b', 'a'])
```

![](/images/posts/77/12.png)

![](/images/posts/77/13.png)

이 상태에서 두 Series를 덧셈하면, 같은 인덱스끼리 덧셈하여, \[a - 2, b - 4, c - 6, d - 10\]이 출력됩니다.

```python
s1 + s2
```

![](/images/posts/77/14.png)

이와 같이 산술 연산은 인덱스가 일치한 스칼라와의 연산이 적용되고, 인덱스의 pair가 불일치하면 NaN이 됩니다.

```python
s1 ** 2
```

![](/images/posts/77/15.png)

```python
s1 ** s2
```

![](/images/posts/77/16.png)

그리고, Series에서의 불린 인덱싱(Boolean Indexing)도 넘파이의 불린 인덱싱(Boolean Indexing)과 동일한 효과입니다.

다음과 같은 Series를 하나 더 만듭니다.

```python
s = pd.Series(np.arange(10), np.arange(10) + 1)
```

![](/images/posts/77/17.png)

그리고 5보다 크고, 짝수인 Series를 골라내 보겠습니다.

```python
s[(s > 5) && (s % 2 == 0)]
```

![](/images/posts/77/18.png)

다음으로, Series 값을 삭제하기 위해서는 drop()을 사용합니다. (참고로 연산 자체는 원본 값에 변화는 없습니다)

하지만, inplace=True 옵션을 주면 원본 변화시키도록 동작합니다.

```python
s.drop(9, inplace=True)
```

![](/images/posts/77/19.png)

Series에서는 인덱스(Index)에 다중 레벨(Multi-Level)을 가질 수 있습니다.

다중 레벨 인덱스(Multi-Level Index)를 가진 Series를 만들어보겠습니다.

```python
s3 = pd.Series(data=np.arange(100, 106), index=[
  ['a', 'a', 'b', 'b', 'c', 'c'],
  [1, 2, 1, 2, 1, 2]
])
```

![](/images/posts/77/20.png)

인덱스에 접근해보면, MultiIndex 객체로 구성됩니다.

```python
s3.index # MultiIndex([('a', 1), ('a', 2), ('b', 1), ('b', 2), ('c', 1), ('c', 2)])
```

따라서, 튜플 인덱싱으로 value 접근이 가능합니다.

```python
s3['a', 1] # np.int64(100)
```

추가로, apply() 함수는 Series의 각 value 원소에 함수를 적용시킬 때 사용하며, 일종의 원소별 변환 역할입니다.

다음과 같은 zero-based Index의 Series가 있다고 가정합시다.

```python
s = pd.Series([1, 2, 3, 4, 5], dtype=int16)
```

각 원소에 제곱을 적용하기 위해서 apply()에 람다 함수를 적용합니다.

```python
result = s.apply(lambda x: x**2)
```

사용자 정의 함수를 만들어 추가 인자를 전달할 수도 있습니다.

```python
def multiply(x, factor):
  return x * factor
  
result = s.apply(multiply, args=(10,))
```

**데이터프레임(DataFrame)**

Series가 1차원이라면, DataFrame은 2차원으로 확대된 버젼이며, 2차원이므로 Index가 row, column으로 구성됩니다.

row는 각 개별 데이터를 column은 데이터의 개별 속성(feature)을 의미합니다.

데이터 분석/머신 러닝에서 데이터 변형을 위해서 많이 사용하는 개념입니다.

먼저 csv 파일을 읽기 위해 메인 폴더 path를 불러옵니다.

```python
base_path = r'c:\Users\haruka\Desktop\AI수업\mcp-month-2\data'
```

분석할 csv에 해당하는 파일을 가져옵니다.

```python
filepath = os.path.join(base_path, 'titanic.csv')
```

read\_csv()를 통해 DataFrame 객체로 읽어옵니다.

```python
df = pd.read_csv(filepath)
```

![](/images/posts/77/21.png)

```python
def load_titanic():
  return pd.read_csv(filepath)
```

함수를 불러와 DataFrame을 출력하면, 0 ~ 890까지의 zero-based Index와 12개의 column을 가집니다.


-   passengerId: 여권 ID

-   Sex: 승객 성별
-   Age: 승객 나이
-   SibSp: 탑승한 배우자들 혹은 형제들

-   Ticket: 티켓 넘버
-   Fare: 여권 요금
-   Cabin: 선실
-   Embarked : 출발지 혹은 승선 탑승지 (C: Cherbourg, Q: Queenstown, S: Southampton)

![](/images/posts/77/24.png)

count(개수), mean(평균값), std(표준편차), min(최소값), max(최대값), 50%(중위), 25%, 75% 값을 제공합니다.

DataFrame 객체에도 Index 속성이 존재합니다. 각 아이템을 특정할 수 있는 고유의 값을 저장합니다.

Series에서처럼 복잡한 데이터의 경우 MultiIndex로 표현할 수 있습니다.


컬럼은 feature(특성), 속성, 필드, 차원 같은 용어로 표현합니다.

```python
df.columns
```

**데이터프레임 수동 생성하기**

DataFrame은 리스트, 튜플, ndarray와 같은 다양한 객체로부터 수동 생성할 수 있습니다.

리스트를 통해 데이터프레임 객체를 만들어보겠습니다.

```python
df = pd.DataFrame([1, 2, 3])
```

![](/images/posts/77/26.png)

결과적으로 리스트의 요소인 1, 2, 3은 각각의 행 데이터로 들어가고 Index와 Columns가 알아서 생성됩니다.

그리고, 아래와 같이 2차원 리스트로 데이터를 넣으면, 순서대로 첫번째 행, 두번째 행 데이터로 들어갑니다.

```python
df = pd.DataFrame([
  [1, 2, 3],
  [4, 5, 6]
])
```

![](/images/posts/77/27.png)

이에 따라 여러가지 속성들을 가지고 있는데, len()을 통해 행의 개수(axis=0)를 알아봅니다.

```python
len(df) # 2
```

shape는 DataFrame의 row, column을 튜플 형식으로 알 수 있습니다.

```python
df.shape # (2, 3)
```

ndim()은 이 DataFrame의 차원의 개수를 알려줍니다.

```python
df.ndim # 2
```

size는 가지고 있는 스칼라 값의 개수를 알려줍니다.

```python
df.size # 6
```

dtypes는 각 column 별 데이터 타입이 시리즈 형식으로 나옵니다.

```python
df.dtypes
```

![](/images/posts/77/28.png)

![](/images/posts/77/31.png)


이것을 통해 만들면, key는 columns에 values는 값에 대응됩니다.


**특정 행 선택하기**

행을 선택할 때는 loc\[\]와 iloc\[\] 속성을 사용합니다.

예제를 이해하기 쉽게 돕기 위해 임의적으로 zero-based Index에 100을 더하겠습니다.

```python
df.index += 100
```

![](/images/posts/77/42.png)

이제 loc를 사용해 접근할 때는 \[ \] 안에 그 행의 인덱스를 적어주면 됩니다. 결과는 Series 입니다.

```python
df.loc[986]
```

위에서 살펴본 원리로 \[ \] 안에 리스트를 넣으면, 차원 변화가 없으므로 DataFrame이 나옵니다.

```python

```

![](/images/posts/77/44.png)

역시 여러 개의 행을 얻기 위해서는 콤마(,)로 구분하여 Index를 적어주면 됩니다.

```python

```

![](/images/posts/77/45.png)

반대로 iloc는 Index의 번호가 아니라 Index의 순서 개념으로 접근합니다.

예를 들어, 0번째 행의 Index를 가져오겠다고 하면, loc는 반드시 첫번째 Index 번호가 0이어야 합니다.

하지만, iloc는 순서로 접근하는 것이기 때문에 몇번째 순서인지만 생각하면 됩니다.

```python

```

![](/images/posts/77/46.png)

같은 원리로, 리스트로 인덱싱하면 DataFrame을 얻을 수 있습니다.

```python
df.iloc[[0, 100, 200, 2]]
```

![](/images/posts/77/47.png)

추가로 이야기할 점은 위에서 말한 loc\[\], iloc\[\]는 행 선택 뿐만 아니라, 컬럼 선택할 때도 사용할 수 있다는 점입니다.

즉, 행과 컬럼을 동시에 선택할 때 tuple을 이용하여 row, column 둘다 명시 가능합니다.

loc의 경우 **loc\[axis=0 row, axis=1 column\]** 형태로 명령하고,

iloc는 **iloc\[zero based row, zero based column\]** 형태로 명령합니다.

loc 먼저 살펴보겠습니다.

```python
# 986번 인덱스, Survived 컬럼 선택

```

![](/images/posts/77/48.png)

iloc의 경우도 살펴보겠습니다.

```python

df.iloc[-5, -3]
```

**상관관계(Correlation)**

정형 데이터에선 여러 개의 컬럼이 있는데 각 컬럼 간의 상관관계가 있을 수도 있습니다.

상관관계라는 것은 두 변수간의 흐름이 얼마나 비슷한가를 나타내는 척도입니다.

가령 a 컬럼의 값이 증가할 때 b 컬럼의 값이 증가 혹은 감소하는지 파악하여 그렇다면 상관관계가 있는 것입니다.

즉, 증감의 성향이 비슷한가를 보는 것입니다. 그러면서, 이 상관관계의 값을 -1 ~ +1 사이로 표현합니다.

+1에 가까울수록 둘은 비슷하게 증감하고, -1에 가까울수록 둘은 반대로 증감합니다.

또한, 절댓값 0에 가까우면 상관관계가 적습니다. 다른 말로 이것을 **피어슨 상관계수**라고도 합니다.

판다스에서는 corr() 함수를 통해 상관계수를 연산합니다.

데이터 타입이 숫자 타입인 경우에만 확인하겠습니다.

```python
df.corr(numeric_only=True)
```

![](/images/posts/77/54.png)

위 결과를 보면, 2개의 컬럼 간의 상관관계를 보는 것이므로, 주대각선은 모두 +1 값을 가집니다.

여기서는 Fare와 Pclass가 상대적으로 절댓값이 높은 분포를 가집니다. Pclass가 작아질수록 Fare는 올라갑니다.

**수치형 데이터 & 범주형 데이터**

**수치형 데이터**는 데이터의 특성이 연속성을 띄는 숫자로 이루어진 데이터를 말합니다.

그리고, 대소비교가 가능하고 산술연산(평균, 합계, 중간값)이 의미가 있어야 합니다.

**범주형(분류형) 데이터**는 연속적이지 않은 값(대부분 숫자를 제외한 나머지)을 갖는 데이터를 의미합니다.

어떤 경우, 데이터 타입이 숫자형이어도 개념적으로 범주형으로 처리해야 할 경우도 있습니다.

예를 들어, 대한민국 우편번호는 숫자로 이루어져 있습니다.

역삼동은 06240이고, 애월읍은 63131입니다. 그러면, 애월읍은 역삼동의 약 10.11배라고 표현합니까?

이런 산술 연산 비교가 의미가 없으므로, 범주형 데이터로 분리합니다.

따라서, 대소비교가 불가하고, 산술연산(평균, 합계, 중간값)이 의미가 없어야 합니다.

그래서 이번에는 Age 컬럼의 데이터를 10대, 20대, 30대 이런 식으로 범주형 데이터로 변환해보겠습니다.

apply() 함수를 통해 맵핑해야 하므로, 먼저 함수를 정의합니다.

```python
def age_categorize(age):
  if np.isnan(age):
    return -1
  return int(age / 10) * 10
```

그리고, 특정 컬럼(현재는 Age 컬럼)에 함수를 apply() 합니다.

```python
age_span = df['Age'].apply(age_categorize)
```

![](/images/posts/77/60.png)

분류형 데이터로 제대로 구분되었는지 unique() 통해 확인합니다.

```python
age_span.unique() # array([20, 30, -1, 50,  0, 10, 40, 60, 70, 80])
```

또, 각각의 나이대별로 몇개의 데이터가 있는지 value\_counts()를 통해 확인합니다.

```python
age_span.value_counts()
```

![](/images/posts/77/61.png)

위 정보를 파생변수로 따로 저장합니다.

```python
df['Age_span'] = age_span
```

**원-핫 인코딩 (One-Hot Encoding)**

범주형 데이터를 수치화 해야할 필요가 있을 때 원-핫 인코딩(One-Hot Encoding)을 사용합니다.

가령 어떤 컬럼의 데이터가 Red, Green, Blue 3가지가 있다고 가정해보겠습니다.

기본적으로 범주형 데이터는 연산이 불가합니다. 따라서 연산 처리가 가능하도록 데이터를 바꿔주어야 합니다.

범주형 데이터의 컬럼 1개를 범주의 개수만큼 늘려서 범주에 해당하는 값에만 1을 주고, 나머지는 0을 주어 처리합니다.

3가지 범주값이 있는 현재 상황에서, Red / Green / Blue 3개의 컬럼으로 만들어

Red는 Red일 경우에만 1, 나머지는 0 / Green은 Green일 경우에만 1, 나머지는 0 / Blue는 Blue일 경우에만 1, 나머지는 0

이런 방식으로 변환시키는 겁니다.

위에서 살펴본 데이터에서는 Pclass 데이터를 예시로 잡겠습니다. 먼저 유니크한 값들이 몇개인지 확인합니다.

```python
df['PClass'].unique() # array([3, 1, 2])
```

총 3가지의 범주값이 나오는데, 판다스에서 get\_dummies() 함수를 이용해

범주형 데이터에 대해 원-핫 인코딩을 수행합니다.

다만 여기서는 Pclass, Sex, Embarked 컬럼에만 지정합니다.

그리고, drop\_first=True 옵션을 통해 첫번째 컬럼은 제외시킵니다.

```python
pd.get_dummies(df, columns=['Pclass', 'Sex', 'Embarked'], dtype=int, drop_first=True)
```

![](/images/posts/77/63.png)

이렇게 하면 범주형 데이터도 연산이 가능한 형태가 되었다고 했는데

그 의미는 머신러닝을 하다보면, 범주형 데이터에 대한 예측값이 \[1, 0, 0\] 이런식으로 정확히 나오지 않습니다.

수많은 연산을 통해 \[0.982, 0.0003, 0.0004\] 이런 식으로 나오는데

\[1, 0, 0\] / \[0, 1, 0\] / \[0, 0, 1\] 3개 중 무엇에 가까운지 판단할 수 있는데 이것도 산술 연산 과정인 것입니다.

다음으로, groupby에 함수를 전달하여 리턴하는 값을 grouping 기준으로 삼을 수 있습니다.

함수의 매개변수는 각 행의 Index를 받아야 합니다.

먼저 이전에 만들어둔 age\_categorize() 함수를 참고해봅시다.

```python
def age_categorize(age):
  if np.isnan(age):
    return -1
  return int(age / 10) * 10
```

여기서 Age 컬럼 데이터에 대해 age\_categorize 기준으로 grouping 합니다.

```python
df.set_index('Age').groupby(age_categorize).size()
```
