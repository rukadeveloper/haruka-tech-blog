**사업장명 정리하기**

사업장명 컬럼의 데이터가 (주)나 \[주식회사\]가 들어간 문자열은 제거합니다.

또 숫자, 한글, 영어를 제외한 특수문자는 공백으로 대체하고, 공백이 1개 이상 들어간 경우 1개로 대체하겠습니다.

먼저 첫번째로, (주)가 들어간 회사명에서 (주)를 제거하겠습니다.

해당 컬럼에 접근하면 Series가 나오는데 추가로 str 속성에 접근하면 StringMethods 객체를 리턴합니다.

```python
df['사업장명'].str # <pandas.core.strings.accessor.StringMethods at 0x23f3c5c06e0>
```

이는 문자열 데이터에서 일괄적으로 적용할 수 있는 문자열 연산을 제공하는 접근자입니다.

즉 Python의 문자열 메서드를 Series 전체에 한번에 적용할 수 있도록 하는 기능을 제공합니다.

우리는 contains()를 사용하여 (주) 문자열이 포함되었는지 검사합니다.

결과적으로 Boolean Mask Series를 리턴합니다.

```python
df['사업장명'].str.contains(r'\(주\)')
```

![](/images/posts/79/4.png)

이 Mask Series를 이용해 loc를 통해 Boolean Indexing 합니다.

```python
ju_loc = df.loc[df['사업장명'].str.contains(r'\(주\)')]
```

![](/images/posts/79/5.png)

이제 정규표현식을 이용해 (주)라는 글자를 제거해보겠습니다. (예시로 첫 데이터만 적용하겠습니다.)

```python
pattern1 = r'(\([^)]+\))'
re.sub(pattern1, '', '우성기전(주)') # '우성기전'
```

다음 두번째로, \[\]가 들어간 회사명에서 \[\]를 제거하겠습니다.

```python
bracket_loc = df.loc[df['사업장명'].str.contains(r'\[')]
```

![](/images/posts/79/6.png)

이제 정규표현식을 이용해 \[ \] 안의 회사명 글자를 제거해보겠습니다. (예시로 첫 데이터만 적용하겠습니다.)

```python
pattern2 = r'(\[[^)]+\])'
re.sub(pattern2, '', '에스티테크[주]') # 에스티테크
```

다음 세번째로 사업장명에 특수문자가 있는 경우를 살펴보겠습니다.

```python
special_loc = df.loc[df['사업장명'].str.contains(r'\/')]
```

![](/images/posts/79/7.png)

이제 정규 표현식을 이용해 숫자를 알파벳, 숫자, 한글 제외한 특수문자를 제거합니다. (예시로 예시 데이터만 적용합니다.)

```python
pattern3 = '[^A-Za-z0-9가-힣]'
result = re.sub(pattern3, ' ', '*&&^%의료법인%해정') # '     의료법인 해정'
```

그리고, 공백 여러개는 1개로 바꿉니다.

```python
result = re.sub(' +', ' ', result).strip() # '의료법인 해정'
```

최종적으로 전처리 되기 이전 데이터는 다음과 같습니다.

```python
df.loc[[0, 112863, 718]]
```

![](/images/posts/79/8.png)

이제 위 내용을 기반으로 전처리하는 함수를 만들겠습니다.

```python
def preprocessing(x):
  x = re.sub(pattern1, '', x)
  x = re.sub(pattern2, '', x)
  x = re.sub(pattern3, ' ', x)
  x = re.sub(' +', ' ', x)
  return x.strip()
```

최종적으로 사업장명 컬럼에 대해 함수를 apply하면 됩니다.

```python
df['사업장명'] = df['사업장명'].apply(preprocessing)
```


이제 국민연금납부액으로 기업별 평균 연봉을 역추정해보겠습니다. 

국민연금 보험률은 9%인데, 쉽게 이야기해서 급여의 9%를 국민연금으로 내는 것입니다.

이 중 4.5%는 회사가, 나머지 4.5%는 개인이 부담하는 구조입니다.

국민연금 보험료는 소득 상한선과 하한선이 설정되어 있어 소득 전체가 아닌 일부 소득에만 부과됩니다.

따라서 국민연금납부액만으로 기업별 평균 연봉을 역추산하는 것은 한계가 있습니다.

상한선과 하한선이 있어 실제보다 과소계산될 수 있습니다.

월급여추정은 **인당금액 / 9% \* 100%**으로 계산할 수 있습니다.

이에 따라, 파생변수인 **인당 금액, 월급여추정, 연간급여추정**을 추가해보겠습니다.

인당금액은 금액을 가입자수로 나눈 값입니다.

```python
df['인당금액'] = df['금액'] / df['가입자수']
```

월급여추정은 인당금액을 9%로 나누고 100%를 곱합니다.

```python
df['월급여추정'] = df['인당금액'] / 9 * 100
```

연간급여추정은 월급여추정에 12를 곱합니다.

```python
df['연간급여추정'] = df['월급여추정'] * 12
```

최종적으로 다음과 같이 파생변수가 추가됩니다.

기업을 필터링할 것인데 가입자수를 1000명을 초과하는 기업만 필터링합니다.

단, 연간급여추정 및 가입자수로 내림차순 정렬하고, 사업장명 / 가입자수 / 월급여추정 / 연간급여추정만 출력합니다.

```python
cond = df['가입자수'] > 1000
df.sort_values(['연간급여추정', '가입자수'], ascending=False)\
  .loc[cond, ['사업장명', '가입자수', '월급여추정', '연간급여추정']]
```

![](/images/posts/79/12.png)

그리고, 사업장명을 검색해 결과를 반환하는 함수를 만드는데, 함수명은 find\_company() 입니다.

매개변수로 contains를 추가해 True일 경우 포함하는 모든 회사를 찾고, False일 경우 완벽히 일치하는 회사만 찾습니다.

최종적으로 사업장명 / 월급여추정 / 연간급여추정 / 업종코드를 보여주는 DataFrame을 반환합니다.

```python
def find_company(company_name, contains):
  if contains:
    return df.loc[
      df['사업장명'].str.contains(company_name),
      ['사업장명', '월급여추정', '연간급여추정', '업종코드', '가입자수']
    ].sort_values('가입자수', ascending=False)
  else:
    return df.loc[
      df['사업장명'] == company_name,
      ['사업장명', '월급여추정', '연간급여추정', '업종코드', '가입자수']
    ].sort_values('가입자수', ascending=False)
```

이 함수대로 **에스케이텔레콤**이라는 회사를 먼저 일치하는 것만 찾아봅니다.

```python
find_company('에스케이텔레콤', False)
```

그리고 마지막으로 업종코드가 동일한 회사를 비교해보겠습니다.

먼저 회사의 기본정보를 반환하는 함수인 company\_info() 함수를 만듭니다.

```python
def company_info(company_name):
  company = find_company(company_name, True)
  return df.loc[company.iloc[0].name] # 검색된 company중 가입자수가 많은 회사 1개
```

그리고, 주어진 사업장과 업종코드가 동일한 회사를 비교하는 compare\_company() 함수를 만듭니다.

최종적으로 월급여추정과 연간급여추정의 평균, 총 개수, 최소값, 최대값을 보여줍니다.

```python
def compare_company(company_name):
  company = find_company(company_name, True)
  code = company['업종코드'].iloc[0]
  df1 = df.loc[df['업종코드'] == code, ['월급여추정', '연간급여추정']]\
          .agg(['mean', 'count', 'min', 'max'])
  df1.columns = ['업종_월급여추정', '업종_연간급여추정']
  df1 = df1.T
  df1.columns = ['평균', '개수', '최소', '최대']
  df1.loc['업종_월급여추정', company_name] = company['월급여추정'].values[0]
  df1.loc['업종_연간급여추정', company_name] = company['연간급여추정'].values[0]
  return df1
```

```python
class PensionData():
  def __init__(self, filePath):
    warnings.simplefilter(action='ignore', category=pd.errors.DtypeWarning)
    self.df = pd.read_csv(os.path.join(filePath), encoding='cp949')
    self.pattern1 = r'(\([^)]+\))'
    self.pattern2 = r'(\[[^)]+\])'
    self.pattern3 = r'[^A-Za-z0-9가-힣]'
    self.preprocess()
      
  def preprocess(self):
    
    # 사업자업종코드 컬럼값이 빈 문자열인 것들은 제거
    mask = self.df['사업장업종코드'].replace({r'^\s+$': pd.NA}, regex=True).isna()
    self.df = self.df[~mask]
    self.df['사업장업종코드'] = self.df['사업장업종코드'].astype('int32')
    
    # 컬럼명들 재정의
    self.df.columns = [
      "자료생성년월", "사업장명", "사업자등록번호", "가입상태", "우편번호",
      "사업장지번상세주소", "주소", "고객법정주소코드", "고객행정주소코드",
      "시도코드", "시군구코드", "읍면동코드",
      "사업장형태구분코드 1 법인 2 개인", "업종코드", "업종코드명",
      "적용일자", "재등록일자", "탈퇴일자",
      "가입자수", "금액", "신규", "상실"
    ]
    
    # 불필요한 컬럼 제거
    df = self.df.drop([
      '자료생성년월', '우편번호', '사업장지번상세주소', '고객법정동주소코드',
      '고객행정동주소코드', '사업장형태구분코드 1 법인 2 개인', '적용일자',
      '재등록일자'
    ], axis=1)
    
    # 사업장명 cleasing
    df['사업장명'] = df['사업장명'].apply(self.preprocessing)
    
    # 탈퇴일자_연도, 탈퇴일자_월 추가
    df['탈퇴일자_연도'] = pd.to_datetime(df['탈퇴일자']).dt.year
    df['탈퇴일자_월'] = pd.to_datetime(df['탈퇴일자']).dt.month
    
    # 주소 컬럼에서 시도 부분만 새 컬럼으로 추가
    df['시도'] = df['주소'].str.split(' ').str[0]
    
    # 탈퇴한 기업들은 drop
    df = df.loc[df['가입상태'] == 1].drop(['가입상태', '탈퇴일자'], axis=1)\
           .reset_index(drop=True)
           
    # 분석하고자 하는 컬럼 추가
    df['인당금액'] = df['금액'] / df['가입자수']
    df['월급여추정'] = df['인당금액'] / 9 * 100
    df['연간급여추정'] = df['월급여추정'] * 12
    
    # 원본변경
    self.df = df
    
  def preprocessing(self, x):
    x = re.sub(self.pattern1, '', x)
    x = re.sub(self.pattern2, '', x)
    x = re.sub(self.pattern3, ' ', x)
    x = re.sub(' +', ' ', x)
    return x.strip()
    
  # 주어진 company_name으로 검색하기
  def find_company(self, company_name):
    # 가입자가 많은 순으로 정렬하여 return
    return self.df.loc[
      self.df['사업장명'].str.contains(company_name),
      ['사업장명', '월급여추정', '연간급여추정', '업종코드', '가입자수']
    ].sort_values('가입자수', ascending=False)
    
  # 동종업계 정보(월급여추정액, 연간급여추정액) 비교
  def compare_company(self, company_name):
    company = self.find_company(company_name)
    code = company['업종코드'].iloc[0]
    df1 = self.df.loc[
      self.df['업종코드'] == code, 
      ['월급여추정', '연간급여추정'].agg(['mean', 'count', 'min', 'max'])
    ]
    df1.columns = ['업종_월급여추정', '업종_연간급여추정']
    df1 = df1.T
    df1.columns = ['평균', '개수', '최소', '최대']
    df1.loc['업종_월급여추정', company_name] = company['월급여추정'].values[0]
    df1.loc['업종_연간급여추정', company_name] = company['연간급여추정'].values[0]
    return df1
    
  # 검색 기업 정보 출력
  def company_info(self, company_name):
    company = self.find_company(company_name)
    return self.df.loc[company.iloc[0].name]
    
  def get_data(self):
    return self.df
```
