<img src="/media/images/uploads/1793750661634.png" width="636" data-align="left" style="display: block; height: auto; max-width: 100%; margin: 0px auto 0px 0px;"><h3><strong>백엔드 엔지니어란?</strong></h3><p>백엔드 엔지니어란 서버 사이드(Server Side) 프로그램을 디자인하고 개발, 유지보수하는 역할을 합니다.</p><p>백엔드는 REST API, GraphQL, gRPC 프로토콜 등을 통해 프론트엔드가 통신할 수 있는 영역입니다.</p><img src="/media/images/uploads/1793750831124.png" width="580" data-align="left" style="display: block; height: auto; max-width: 100%; margin: 0px auto 0px 0px;"><p>백엔드를 조금 더 세분화하여 얘기하자면, API Server / Database / Infrastructure로 구분됩니다.</p><p><strong>API Server</strong>는 프론트엔드와 백엔드 혹은 백엔드끼리의 연결을 가능하게 해주는 영역입니다.</p><p>즉, 프론트엔드에서 요청이 왔을 때 실제 비즈니스 로직을 수행하는 곳입니다.</p><p>관련된 키워드로는 Nest.js / Django / Spring / GraphQL / REST API / gRPC 등이 있습니다.</p><p><strong>Database</strong>는 데이터 저장소입니다. API Server에서 비즈니스 로직을 수행할 때 잊어버리는 안되는 정보들</p><p>예를 들어, 인스타그램에서 올린 Post의 제목, 내용, 이미지들, 좋아요 개수 등을 서버에서 기억해야 합니다.</p><p>API Server에서 Database에 전송을 한 다음에 Database에 입력을 해서 데이터가 사라지지 않도록</p><p>저장하는 공간입니다.</p><p>관련 키워드로는 Postgresql / MySQL / OracleDB / MongoDB / DynamoDB 등이 있습니다.</p><p><strong>Infrastructure</strong>는 백엔드를 실행하는 하드웨어를 관리하는 영역입니다.</p><p>Cloud Engineer 혹은 DevOps Engineer들이 이쪽에 속하는 엔지니어들입니다.</p><p>키워드는 Cloud, Kubernetics, DevOps 등이 있습니다.   </p><img src="/media/images/uploads/1793751528745.png" width="654" data-align="left" style="display: block; height: auto; max-width: 100%; margin: 0px auto 0px 0px;"><h3>Node.js 소개</h3><p>Node.js란 오픈소스 / 크로스 플랫폼 / 자바스크립트 런타임 엔진입니다.</p><ul><li><p>오픈소스는 누구나 볼 수 있도록 소스 코드가 공개되어 있다는 의미입니다.</p></li><li><p>크로스 플랫폼은 여러 OS에서 사용할 수 있다는 의미입니다.</p></li><li><p>자바스크립트 런타임은 자바스크립트를 실행할 수 있다는 의미입니다.</p></li></ul><p>실제로, <a target="_blank" rel="noopener noreferrer nofollow" href="https://github.com/nodejs/node">https://github.com/nodejs/node</a> 에서 확인할 수 있습니다. </p><p>Node.js 즉 자바스크립트는 인터프리터 언어 중에 하나인데, 컴파일 언어와의 차이점을 이해할 필요가 있습니다.</p><ul><li><p>컴파일 언어 : 프로그램을 실행하기 전에 작성된 코드를 기계어로 한번에 변환한 후 실행합니다.</p></li><li><p>인터프리터 언어 : 프로그램을 실행하면서 동시에 코드를 한줄 한줄씩 변환하면서 실행합니다.</p></li></ul><p>그 중 V8 자바스크립트 엔진은 JIT 컴파일러를 사용합니다.</p><p>JIT (Just In Time) 컴파일러는 컴파일 방식과 인터프리터 방식의 장점을 모아둔 형태입니다.</p><p>과정은 다음과 같습니다.</p><ol><li><p>코드 실행 환경을 준비하고, 컴파일을 합니다.</p></li><li><p>바이트 코드로 생성 및 변환합니다.</p></li><li><p>Ignition 툴을 사용해 인터프리터 방식으로 실행합니다.</p></li><li><p>이 중 자주 쓰는 코드를 최적화하여 Turbofan 툴로 머신 코드로 변환하고 컴파일합니다.</p></li><li><p>최적화를 해놓은 코드가 변경이 되었다면, 최적화를 풀어 바이트 코드로 변환해 인터프리터 방식으로 바꿉니다.</p></li></ol><p></p>
