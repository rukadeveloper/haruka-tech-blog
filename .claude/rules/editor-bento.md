# 글 에디터 (벤토 블록 에디터) 규칙

`/admin/posts/new`, `/admin/posts/[slug]/edit` 의 글 에디터는 **벤토 블록 에디터**입니다. 글의 블록(커버, 제목, 문단, 코드, 콜아웃 …) 하나하나를 둥근 카드로 보여 주고, 왼쪽은 글 편집 영역, 오른쪽은 발행 보조 정보를 벤토 그리드로 모은 사이드 패널입니다. 깔끔하고 단단한 느낌 — 장식은 최소, **카드 크기 대비와 포인트 컬러 하나로 리듬**을 만듭니다. 아래 값은 임의로 바꾸지 않습니다.

## 이 화면만의 예외

- DESIGN.md 의 블로그 색 · 글꼴(Pretendard) 대신 아래 토큰과 글꼴을 씁니다. 공개 화면과 다른 관리자 화면(`(site)`)은 바꾸지 않습니다.
- 적용 방식: `StudioTheme` 이 에디터가 보이는 동안만 `html` 에 `data-studio` 를 붙이고, `studio.css` 의 `html[data-studio]` 가 블로그 전역 토큰(`--background`, `--elevated`, `--surface`, `--line`, `--foreground`, `--muted`, `--meta`, `--strong`, `--on-strong`, `--success`, `--danger`, `--warning` …)을 아래 값으로 덮어씁니다. `globals.css` 가 `@theme inline` 이라 `.btn`, `.field`, `.badge`, `Select`(body 로 띄우는 목록 포함) 같은 기존 부품이 그대로 벤토 색이 됩니다.
- `:has()` 로 화면 안의 표식을 찾아 테마를 바꾸지 않습니다 (cacheComponents 가 떠난 화면의 DOM 을 남겨 둠 — CLAUDE.md "인트로 페이지").
- 그대로 지키는 규칙: 라이트 · 다크 모두 지원, 모바일 퍼스트, 코드 주석과 화면 문구는 한국어, 움직임은 DESIGN.md 의 `--ease-out` · `--dur*` · `--press*` 토큰.

## 레이아웃 (데스크톱 1440px 기준)

1. **상단 바** (흰 카드, sticky): 로고 "dev.log" · "새 글 / 글 수정 · 블록 N개" · 저장 상태 | [임시저장] [미리보기] [발행 →](포인트색). 발행된 글은 "업데이트 →".
2. **메인 열** (남는 폭 전부): 커버 이미지 드롭존(점선, "1200×630 권장") → 제목 카드(태그 칩 · 제목 · 리드 문단) → 본문 블록 카드들 → 블록 추가 메뉴. 아래 가운데에 진한 서식 알약.
3. **사이드 열** (360px, 2열 그리드, lg 이상 sticky):
   - 발행 전 체크 (2칸)
   - 글자 수 · 읽는 시간 (각 1칸, 큰 숫자)
   - 카테고리 (2칸) · 목차 (2칸)
   - 블록 구성 · 마지막 저장 (각 1칸)
   - URL · 날짜 · 추천 (2칸)
- lg(1024px) 미만: 한 열 — 상단 바 → 메인 → 사이드 그리드(2열 유지), 바깥 여백 12px.

## 블록 카드 규칙 (`.bento-doc`, ProseMirror 루트의 자식)

- 글 덩어리 M = `h2, p, ul, ol, h3, h4, blockquote`. 이어지는 것 C = `p, ul, ol, h3, h4, blockquote`.
- **H2 마다 새 카드**가 시작되고, 그 뒤의 문단 · 목록 · H3 는 같은 카드로 이어집니다. 그 밖의 블록이 끼면 카드가 끊깁니다.
  - 시작: `> h2`, `> C:first-child`, `> :not(M) + C` → 위 모서리 20 · 위 여백 12 · 안쪽 위 28
  - 끝: `> M:not(:has(+ C))` → 아래 모서리 20 · 안쪽 아래 28 (형제 관계만 보는 `:has()` 라 위 예외 규칙과 무관)
  - 좌우 안쪽 32px(모바일 20px), 블록 사이 간격은 margin 대신 padding.
- 그 밖의 블록은 **각자 카드**: 코드(`pre`) = 진한 카드, 콜아웃 = `#FFF4D6` 카드, 파일 트리 · 표 · 이미지 = 흰 카드(r20, p20). `hr` 은 카드 없이 옅은 선. 모두 위 여백 12.
- 커서가 들어 있는 블록(선택된 노드)은 포인트색 2px 외곽선.

## 콜아웃 블록

- 저장 형태 `<div data-callout="warning">…블록…</div>` (Tiptap 노드 `callout`, `extensions/Callout.ts`). 지금 종류는 `warning`(주의) 하나.
- 공개 글에서는 `globals.css` 의 `.post-body div[data-callout]` 가 블로그 토큰(`--warning-soft`)으로 그립니다.
